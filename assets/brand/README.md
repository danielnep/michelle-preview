# Monograma MC · Michelle Cândido
Arte-mestra vetorial: \`mc-symbol.svg\`. Letras geométricas M e C, contraste tecnológico azul-celeste, prata e um toque malva discreto sobre azul-noite. Arte desenhada para o projeto da Michelle; inspiração estética da Horizon sem qualquer assinatura da Horizon na interface do cliente.

## Variantes
- \`mc-symbol.svg\`: símbolo mestre, fundo azul-noite; favicons e PWA
- \`mc-symbol-light.svg\`: ícone para suportes claros
- \`mc-symbol-mono.svg\`: alternativa monocromática clara
- Para PNG 16, 32, 48, 180, 192, 512, 1024: exportar a partir do SVG mestre sem distorcer a proporção.
- Para ícone maskable: manter as letras dentro da área central e testar o recorte circular/Android.

**Atenção:** SVG é o master editável autêntico. O pacote PNG só deve ser considerado final após gerar e conferir cada tamanho. O ícone deve ser validado em tamanhos mínimos antes da publicação final.
