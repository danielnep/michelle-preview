# Painel Completo | Michelle

Painel responsivo de inteligência operacional da Michelle, desenvolvido para demonstração pela Horizon.

## Funcionalidades
- Oito setores operacionais, dashboards, gráficos e filtros.
- Importação de CSV/XLSX e relatórios.
- Assistente para análises de indicadores e conversa geral demonstrativa.
- Estúdio de Apresentações com cinco modelos, editor de slides, três estilos e exibição em tela cheia na TV.
- Dados fictícios identificados e persistência local no navegador.

## Como abrir
Abra `index.html` no navegador ou publique este repositório usando GitHub Pages.

## Limites da demonstração
Não há conexão ativa com Sigware ou um serviço externo de IA generativa. As planilhas importadas e apresentações ficam salvas apenas no navegador. Para arquivos XLS/XLSX, o leitor externo SheetJS depende de conexão à Internet.

## Atualizações
O branch `main` é a origem da versão publicada. Novas versões são enviadas em commits explícitos quando as alterações forem concluídas; não há sincronização automática.
